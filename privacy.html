隱私權政策

最後更新：2026 年 11 月 6 日

本政策說明「今天有點意思 自動上傳」（以下稱「本程式」）如何使用透過 Google 帳戶授權取得的資料。

本程式是什麼

本程式由「今天 有點意思!」頻道主自行建立，只用來管理頻道主自己的頻道，例如上傳頻道主拍攝的影片、管理影片留言、讀取頻道數據。本程式不提供給其他人使用。

會存取哪些資料

經頻道主本人在 Google 授權畫面同意後，本程式會透過 YouTube API 存取：

  • 頻道基本資料（頻道名稱、頻道 ID），用來確認授權到正確的頻道
  • 上傳影片、設定影片標題、說明與縮圖
  • 頻道影片的留言（例如置頂說明留言）
  • 頻道的觀看數據（YouTube Analytics），用來產生每週成效報告

資料如何使用與保存

  • 授權憑證只保存在頻道主私人的 GitHub 專案加密設定（GitHub Secrets）中，不會公開。
  • 資料只用於上面列出的用途，不會出售、不會分享給第三方，也不會用於廣告。
  • 頻道數據報告只提供給頻道主本人。

本程式使用 Google API 取得的資料，遵守 Google API 服務使用者資料政策，包括「有限使用」的規定。本程式使用 YouTube API 服務，也適用 YouTube 服務條款 與 Google 隱私權政策。

如何取消授權

隨時可以到 Google 帳戶的「第三方存取權」 移除本程式的存取權，移除後本程式就無法再存取任何資料。

聯絡方式

對本政策有任何問題，歡迎透過「今天 有點意思!」的 YouTube 頻道或 Instagram 私訊聯絡。

English summary

This app is used solely by the owner of the “今天 有點意思!” channel to manage their own YouTube channel (uploading videos, managing comments, reading channel analytics). Credentials are stored only in the owner's private GitHub Secrets. Data is never sold, shared with third parties, or used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.
