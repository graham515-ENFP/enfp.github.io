隱私權政策

最後更新：2026 年 11 月 7 日

本政策說明「今天有點意思 自動上傳」（以下稱「本程式」）如何使用透過 Google 帳戶及 Meta（Facebook／Instagram）帳戶授權取得的資料。

本程式是什麼

本程式由「今天 有點意思!」頻道主自行建立，只用來管理頻道主自己的頻道，例如上傳頻道主拍攝的影片、管理影片留言、讀取頻道數據。本程式不提供給其他人使用。

會存取哪些資料

經頻道主本人在 Google 授權畫面同意後，本程式會透過 YouTube API 存取：

  • 頻道基本資料（頻道名稱、頻道 ID），用來確認授權到正確的頻道
  • 上傳影片、設定影片標題、說明與縮圖
  • 頻道影片的留言（例如置頂說明留言）
  • 頻道的觀看數據（YouTube Analytics），用來產生每週成效報告

經頻道主本人在 Facebook 授權畫面同意後，本程式會透過 Meta 的 API 存取：

  • 頻道主管理的 Facebook 粉絲專頁與連結的 Instagram 專業帳號的基本資料（名稱、ID）
  • 在上述粉絲專頁與 Instagram 帳號發布影片與貼文
  • 上述帳號貼文的留言（例如置頂說明留言）與成效數據

資料如何使用與保存

  • 授權憑證只保存在頻道主私人的 GitHub 專案加密設定（GitHub Secrets）中，不會公開。
  • 資料只用於上面列出的用途，不會出售、不會分享給第三方，也不會用於廣告。
  • 頻道數據報告只提供給頻道主本人。

本程式使用 Google API 取得的資料，遵守 Google API 服務使用者資料政策，包括「有限使用」的規定。本程式使用 YouTube API 服務，也適用 YouTube 服務條款 與 Google 隱私權政策。

如何取消授權

隨時可以到 Google 帳戶的「第三方存取權」 移除本程式的存取權，移除後本程式就無法再存取任何資料。

Facebook／Instagram：到 Facebook「設定和隱私 → 設定 → 商業整合」（或「應用程式和網站」）移除本程式即可。

資料刪除說明

本程式不會在自己的伺服器保存任何使用者資料，只在頻道主私人的 GitHub 專案加密設定中保存授權憑證。要刪除這些資料：

  1. 依上方「如何取消授權」移除本程式在 Google 或 Facebook／Instagram 的存取權，憑證會立即失效。
  2. 如需協助刪除，請透過下方聯絡方式告知，我們會在 30 天內刪除相關憑證並回覆確認。

聯絡方式

對本政策有任何問題，歡迎透過「今天 有點意思!」的 YouTube 頻道或 Instagram 私訊聯絡。

English summary

This app is used solely by the owner of the “今天 有點意思!” channel to manage their own YouTube channel, Facebook Page and linked Instagram professional account (publishing videos, managing comments, reading analytics). No user data is stored on any server; to delete data, revoke the app's access in your Google or Facebook settings, or contact us and we will delete stored credentials within 30 days. Credentials are stored only in the owner's private GitHub Secrets. Data is never sold, shared with third parties, or used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.
